Program Risk & Compliance Copilot

ML slip-risk prediction + RAG over DORA, GDPR and PSD2 + an LLM agent that drafts steering-committee briefings, under guardrails and human approval. Every number below is measured.

1 · Regulation search (RAG)

Hybrid search (BM25 keywords + LSA embeddings, fused with RRF) over 423 article-level chunks of DORA, GDPR and PSD2. Settings were tuned on the dev split; the test split was never used for tuning.

3 · Slip-risk model (ML)

Trained on Apache Jira issues. Label: a concrete release was removed from the issue (placeholders and bulk renames excluded). Time-based split; issues younger than 180 days dropped to avoid survivorship bias.

ModelROC-AUCPR-AUCPrecision @ top 20%Recall @ top 20%Lift

gradient_boosting0.5360.16816%26%1.29×
logistic_no_text0.5930.15516%26%1.32×

Train 4580 / test 1146 issues. A modest but real signal: reviewing the riskiest fifth of work catches about a third of slips. Explainable logistic regression beat gradient boosting, so it ships.

Limitations

  • RAG test set is 30 questions written by the author; a larger, independently written set would be stronger.
  • The slip model was trained on open-source projects; on a fintech program it is one signal among several (domain shift). Scores rank risk; they are not calibrated probabilities.
  • The demo portfolio is fictional. Not legal advice.
